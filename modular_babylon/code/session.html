modular_babylon/code/session.dm

/proc/babylon_ready_clientThe client once /client/New() has finished, else null. GLOB.clients lists a client from early in New(), which then still waits on the player's game (window checks, the chat panel) for a while on a slow first load. Possessing the drone and deleting the new-player mob in that window left the rest of New() working on a deleted mob: a half set-up client stuck on a black screen with only the title music playing, until the player reconnected.
/proc/babylon_loop_failedLogs a failed loop step once a minute per step, so a recurring error cannot flood the log.
